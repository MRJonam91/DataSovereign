# Changelog

## 1.0.0

**IT:** Deleghe temporanee per documenti selezionati, cestino con nuovo consenso dopo il ripristino, verifica di integrità, backup cifrato e ripristino in vault vuoto. La dashboard aggiunge ricerca, paginazione e filtri dell'audit. La CLI aggiunge `doctor`. L'aggiornamento migra il vault alfa esistente e preserva il percorso predefinito.

**EN:** Temporary delegations for selected documents, trash with fresh consent after restore, integrity checks, encrypted backups and recovery into an empty vault. The dashboard adds search, pagination and audit filters. The CLI adds `doctor`. Upgrading migrates the existing alpha vault and preserves its default path.

## 0.1.0-alpha.1 — 2026-10-18

**IT:** Primo rilascio del vault locale Windows: import cifrato, deleghe di lettura per raccolta con scadenza e revoca, API loopback, audit ed export ZIP. Nessun audit di sicurezza indipendente.

**EN:** First Windows local vault release: encrypted import, collection-scoped read delegations with expiry and revocation, loopback API, audit and ZIP export. No independent security audit.
