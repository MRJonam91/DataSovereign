# Sicurezza / Security

**IT:** Questa è un'alfa locale senza audit indipendente. Per segnalare una vulnerabilità, usa **Report a vulnerability** nella scheda Security del repository o contatta privatamente il maintainer tramite GitHub. Non pubblicare exploit o dati sensibili in issue pubbliche. Il maintainer cercherà di confermare la segnalazione e concordare una divulgazione entro 90 giorni, salvo necessità di coordinamento diverso. Leggi il [modello delle minacce](docs/security/alpha-threat-model.md).

**EN:** This is a local alpha without an independent audit. Report vulnerabilities through **Report a vulnerability** on the repository Security tab, or contact the maintainer privately through GitHub. Do not post exploits or sensitive data in public issues. The maintainer aims to confirm reports and coordinate disclosure within 90 days unless a different timeline is needed. Read the [threat model](docs/security/alpha-threat-model.md).
