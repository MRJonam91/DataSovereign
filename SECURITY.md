# Sicurezza / Security

**IT:** Il [modello delle minacce](docs/security/alpha-threat-model.md) descrive le protezioni e il confine di fiducia della 1.0. Per segnalare una vulnerabilità, usa **Report a vulnerability** nella scheda Security oppure contatta privatamente il maintainer tramite GitHub. Invia eventuali riproduzioni con dati sintetici.

**EN:** The [threat model](docs/security/alpha-threat-model.md) describes the protections and trust boundary of 1.0. Report vulnerabilities through **Report a vulnerability** on the repository Security tab or contact the maintainer privately through GitHub. Use synthetic data in reproductions.
