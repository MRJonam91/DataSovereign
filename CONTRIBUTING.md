# Contribuire / Contributing

**IT:** Apri prima una issue per modifiche di sicurezza o al modello dei permessi. Usa soltanto documenti sintetici nei test. Esegui `python -m pytest -q` su Windows e descrivi cosa hai verificato. Non inserire vault, database, token o dati personali. Leggi [CLA](CLA.md) e [licenze](LICENSING.md) prima della pull request.

**EN:** Open an issue before changing security or permission behavior. Use synthetic documents in tests. Run `python -m pytest -q` on Windows and state what you verified. Do not commit vaults, databases, tokens or personal data. Read the [CLA](CLA.md) and [licensing details](LICENSING.md) before a pull request.
